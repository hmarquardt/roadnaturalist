# Offline preparation

`build-ecoregions.py` prepares the EPA Oregon Level III/IV dataset from pinned shapefile ZIPs. `build-roads.py` prepares the Oregon road-centerline pilot from pinned U.S. Census Bureau TIGER/Line 2025 county ROADS ZIPs, writes the road GeoParquet, the test snapshot fixture, and the manifest entry, and can print a read-only EPA overlap check. `build-habitat.py` prepares the bounded Oregon wetland and hydrography datasets from a pinned U.S. Fish & Wildlife Service National Wetlands Inventory state GeoPackage and pinned U.S. Geological Survey NHD High Resolution HU8 extracts. It verifies source digests, selects the analytical window with the GeoPackage's own R-tree index, clips, simplifies, reprojects and measures in DuckDB Spatial, writes both GeoParquet artifacts and their manifest entries, and supports `--verify` (synthetic spatial-math fixtures), `--corridors` (real pilot metrics written to the test expectations fixture), and `--verify-artifacts` (offline digest/readability/expectation check).

`verify-occurrence-live.mjs` is not a data-preparation script: it is the opt-in live check for the occurrence adapters (iNaturalist public API, eBird when `EBIRD_API_KEY` is present). It is read-only, needs no cache, prints per-corridor source summaries, and prints SKIP for eBird without a credential. It never prints or persists the key.

The preparation scripts verify source digests, keep raw source caches out of Git, and preserve dataset entries they do not build when rewriting `data/manifest.json`. Occurrence sources are live APIs rather than prepared artifacts, so they add no manifest entries.

`docs/ECOREGIONS.md`, `docs/ROADS.md`, `docs/HABITAT.md`, and `docs/OCCURRENCE.md` hold the exact commands, source digests, schemas, coverage extents, privacy rules, and scope. Generated small GeoParquet files are committed so local analysis works without production data hosting.
